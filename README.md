# Lunéra Bijoux

E-commerce website for Lunéra Bijoux built with React, TanStack Router/Start, Vite, Tailwind CSS, and Supabase.

## Local setup

```bash
npm install
cp .env.example .env.local
npm run dev
```

## Checks

```bash
npm run lint
npx tsc --noEmit
npm run build
```

## Important

Do not commit Supabase service-role keys, admin passwords, or `.env` files.
